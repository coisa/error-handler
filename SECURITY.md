# Security policy

## Supported releases

Security fixes are provided for the latest stable release of `coisa/error-handler`.
Reports concerning older releases are welcome; upgrade to the latest stable
release to receive fixes.

## Report a vulnerability privately

Use the repository's [private vulnerability reporting channel](https://github.com/coisa/error-handler/security/advisories/new).
Keep suspected vulnerabilities out of public issues until disclosure has been coordinated.

Include:

- The affected package version, PHP version and relevant optional dependencies.
- The impact, required configuration and conditions needed to reproduce it.
- A minimal synthetic reproduction, with expected and observed behavior.
- Any workaround or mitigation you have already verified.

Do not send credentials, tokens, customer data or production logs. Replace real
application records with synthetic examples.

## Ordinary bugs and feature requests

Use [repository issues](https://github.com/coisa/error-handler/issues) for bugs
without a security impact and for feature proposals.
